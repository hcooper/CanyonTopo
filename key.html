Canyon Topo Legend

This legend shows all the symbols and features used in canyon topographic diagrams.

Terrain Features

Terrain Line
Basic terrain line showing canyon walls, cliffs, or general topography. Black solid line.
Traverse Line
Horizontal or angled traverse across canyon. Grey solid line (#666).
Shortened Section
Line with "shorten" marks indicating the section is compressed/not to scale. Two diagonal slashes at midpoint.
Directional Arrow
Line with arrow showing direction of travel or flow.

Rappels

Rappel (Straight)
Vertical or angled rappel shown as a grey line with a dot at the top (anchor point). Description shows length and rope configuration (e.g., "30m DBL").
Rappel (Curved)
Curved rappel showing overhangs or trajectory. Orange handle (editor only) controls curve shape. Description is draggable.

Water Features

Pool
Water-filled pool or pothole. Blue fill with black outline. Supports asymmetric curves (deeper on left or right side).

Anchors

Anchor (Bolt)
Fixed anchor. Shows X marks for each bolt (2 bolts shown). Green dot (editor only) is the connection/snap point. Name is draggable.

Notes and Warnings

Info Note
General information marker. Light blue circle with "i" inside. Text is draggable.
Warning Note
Warning/hazard marker. Yellow triangle with exclamation point. Text is draggable.
Swim Note
Swimming section marker. Blue wavy lines. Text is draggable.
Hydraulic/Keeper Note
Hydraulic or keeper pothole hazard. Blue circular arrows showing recirculation. Text is draggable.
Rockfall Note
Rockfall hazard area. Grey rocks with red downward arrow. Text is draggable.
Name Note
Name label for features (pools, sections, etc.). Centered italic text with box border. Text is draggable.
Bridge Note
Bridge crossing marker. White circle with bridge icon inside. Text is draggable.

Access Points

Exit
Canyon exit point. Black line with arrow at far end pointing away from route. Optional label is draggable.
Entrance
Canyon entrance or mid-route access point. Green line with arrow at near end pointing into route. Optional label is draggable.
Note: All text labels (rappel descriptions, anchor names, note text, access labels) can be moved independently by dragging them in the editor. Green connection points and orange curve handles appear only in the editor, not in exported SVG/PNG.
